Stop 1 of 6 · Mar to Aug 2025

Taking over a production Windows network in two weeks

A 7-user marine-services company was leaving a national MSP. I had two weeks to take over the domain controller, file server, hypervisor, firewall, backups and Microsoft 365 tenant, then run them.

Windows Server 2022Active DirectoryVMware ESXiFortiGateVeeamMicrosoft 365

What I did

  • Inventoried and re-secured about 20 privileged accounts (Domain Admin, ESXi root, iDRAC, vCenter, FortiGate, NAS, switch, CSP global admin), negotiated the global-admin handover from an MFA-locked incumbent account, and set up a documented break-glass admin.
  • Moved Veeam backups for the DC and file server off the old provider's vault to immutable object storage: Backblaze B2 with 30-day Object Lock, then Wasabi with GFS 12/4/7. Defined recovery-time tiers of 4 h, 8 h and 24 h.
  • Replaced Bitdefender with Defender for Endpoint on the server and all 8 workstations, and ProofPoint with Defender for Office 365.
  • Migrated DNS from Rackspace to GoDaddy and cut mail over to Exchange Online, staging TTLs to 300 s and setting SPF, DKIM and DMARC.

How I checked it

  • Restore tests on the new backup chain before relying on it.
  • Safe Links and Safe Attachments validated with EICAR and phishing tests.
  • The live DNS zone verified by export after the mail cutover, and a next-day inbound issue resolved from message traces.
  • Wrote it all down: a security policy, a 4-phase incident-response runbook and a 25-document operations package.

Stop 5 of 6 · Sep 2026

AWS with least privilege and hard limits

The compute behind my trading research and live trading systems runs on EC2. I set it up the way I would for an employer: no long-lived keys, narrow network paths, and changes rehearsed before they run.

EC2IAM instance rolessecurity groupsspot capacityPython / boto3runbooks
  • KeysNo AWS credentials live on my laptop. A controller instance signs every API call with its IAM instance role.
  • NetworkWorkers accept SSH only from the controller's private IP, through a single /32 security-group rule. The controller's public key goes in through user-data; workers hold no keys of their own.
  • CapacityOn 27 Sep 2026, 1,296 backtests ran across two 128-core spot servers in about 1.9 hours for about $8. Both servers were terminated when the run finished.
  • QuotasThe account's 256-vCPU spot quota is shared across projects, so the runbook allows at most two 128-core workers at once.
  • Change controlA resize tool changes instance types only through the EC2 API. It dry-runs every call first, can rehearse the whole flow on a t4g.nano for about a cent, and writes a verdict file for every run.
  • Lesson keptAn in-OS shutdown once deleted an instance on this account, so none of my tools rely on one.
